# local-demo-testing

Example skill for learning how to install and use IdkRx published skills. Published skills teach LLMs and developers how to interact with the IdkRx API for pharmacy search, medication data, and shortage tracking.

## When to use

When testing skill installation from the `idkrx/skills` registry, or when learning how published skills structure API instructions for LLM consumption.

## Instructions

1. Install: `npx skills add idkrx/skills --skill local-demo-testing`
2. Verify: `npx skills list` shows the skill available in your agent
3. Browse the full skills catalog at the [IdkRx Docs](https://docs.idkrx.com/skills)
